Build a full-stack Support Ticketing System web application step-by-step from scratch.

IMPORTANT:
- Do NOT skip steps.
- Build everything in the correct development order.
- After EVERY major step, create/update a `.txt` documentation file explaining:
  - what was done
  - why it was done
  - how the feature works
  - file/folder purpose

TECH STACK:
Frontend:
- React + Vite
- Tailwind CSS
- React Router
- Axios

Backend:
- Node.js
- Express.js

Database:
- PostgreSQL

ORM:
- Prisma

Authentication:
- JWT + bcrypt

Email:
- Nodemailer

Testing:
- Jest + Supertest

Deployment:
- Docker
- GitHub Actions CI/CD

PROJECT GOAL:
A support ticket management system where:
- Customers can create and manage their own tickets
- Agents can view and manage all tickets
- Tickets have statuses, priorities, comments, and notifications
